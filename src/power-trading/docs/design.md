# Power Trading Atlas · 设计与实施

## 教学目标

把“数学与神经网络基础”与“电力交易业务”连成可验证的知识链。统一贯穿工业用户/售电公司视角，同时解释发电、系统运行和储能的角色。不是交易接口，也不输出实盘策略。

学习顺序为六个阶段，每阶段四课：数学（01–04）、神经网络（05–08）、市场（09–12）、预测（13–16）、决策（17–20）、工业应用（21–24）。先修只指向更早章节。课程完整列表以 `src/content/index.ts` 为准。

每课按照“问题与目标 → 原理与紧邻配图 → 代入数字 → 可计算实验 → 误区与边界 → 自检反馈 → 一手来源”的阅读结构组织。图片的读图提示解释各对象与当课概念的关系，正文没有把全部图片堆在文末。

## 内容和语言

- `src/types.ts` 定义章节、模块、实验、来源与语言结构，语言共用ID。
- `src/content/` 是规范数据：中英正文成对，不在缺少英文反馈时展示语言切换。
- `src/content/catalog.ts` 维护六个阶段、来源身份/状态/核对日期，以及双语术语。
- `src/figures.ts` 映射8组概念和对应语言的图像路径。
- `src/export.ts` 与 `scripts/export-book.ts` 从同一份正文导出，不维护另一套手工教材。

课程的数字例题是独立明确的教学设置，不要求每个实验默认参数相同。例题要给单位与代入过程；实验必须标示自身输入单位。特别是第18课的100/110 MW、15分钟案例，传入数量实验前必须先转为25/27.5 MWh。

## 可视化和实验

概念插图使用内置imagegen生成；具体曲线、阶梯、损失与库存由确定性计算结果渲染成SVG/DOM。图示不承担精确矩阵维度、法定流程或数值证据。

12个实验共用生命周期、控件、单位、反馈、重置与预设，但数值计算位于独立的 `src/labs/math.ts`。梯度训练、出清、滚动回测和储能提供手动步进/播放。对 `prefers-reduced-motion` 采用单步；离开页面或页面不可见时停止定时器。

几个需要保持的数值边界：

1. 0.25小时与15分钟等价，不能把MW直接当MWh。
2. 统一边际出清显示短缺；同价组按容量比例分配；阶梯端点使用明确的“最后被接受报价”约定。
3. 两区模型是运输模型。共同高边际成本可能来自发电容量耗尽，不能全部归因于线路拥塞。
4. 双结算只对实际与日前的差额乘实时价，负偏差不自动叫罚款。
5. CVaR使用成本/损失上尾，按离散概率质量截取边界。
6. 储能库存受双向效率及功率/容量限制。剩余库存与初始库存不同时不将现金流直接作为完整循环收益。
7. 时序预测同时检查目标时刻和信息发布时间。全天日前预测不能使用尚未发生的“昨日同刻”实际量。

## 阅读界面

复用此前LLM教程已验证的轻量阅读壳、KaTeX渲染、对话框和视觉变量，适配为本主题的独立源文件。没有导入或修改LLM功能分支，也没有耦合其构建产物。

导航以hash路由运行，支持子路径静态部署。侧栏保持滚动与展开状态；列表有搜索、分类和空态。读图弹窗有语言一致的下载链接。键盘可使用跳转正文、搜索快捷键、Esc关闭、焦点回收和手机菜单焦点约束。

主题保持暖橙/米色和中性暖灰暗色，正文采用清晰层级和足够行距。仅存储语言、主题、字号；没有学习进度功能或用户分析网络请求。

## 来源维护

官方规则与数学原理分开表达。各来源保留可检索题名、作者、年份、HTTPS入口、状态和核对日期。规则查证记录在 [market-sources.md](market-sources.md)。未来更新需同步受影响的中英正文、算例、实验与教材导出，不能只改来源日期。

## 验收方法

数值测试覆盖会改变教学结论的边界；内容测试覆盖先修、语言、引用、图片、公式解析和导出完整性。真实浏览器测试使用生产构建，覆盖两种语言、桌面/手机、所有课程与实验，以及交互、资源与横向溢出。代表截图用于人工检查视觉质量。具体执行证据写入 [verification.md](verification.md)。

站点在 `src/power-trading` 独立构建，根目录只更新索引、该站点CI及项目会话记录。其他教程的章节ID、页面和构建保持原状。
