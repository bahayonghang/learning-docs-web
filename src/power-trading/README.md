# Power Trading Atlas · 电力交易交互教程

[English README](README.en.md)

从数学与神经网络起步，通过电力系统、市场机制、预测和决策，理解一位工业用户或售电从业者怎样把信息变成可解释的采购安排。课程采用中文与英文完整双语，使用暖橙浅色/深色主题、生成式概念插图和本地计算实验。

## 本地启动

需要 **Node.js 22.12 或更新版本**。本目录独立运行，仓库根目录没有共用开发服务器。

```bash
cd src/power-trading
npm ci
npm run dev
```

打开 Vite 显示的本机地址。已安装 [just](https://just.systems/) 时，可在本目录运行 `just dev`；它会在依赖缺失或锁文件变化时准备依赖，并支持 Windows 的 `npm.cmd`。

```bash
npm run check       # 导出教材、数值/内容测试、类型检查、生产构建
npm run preview     # 预览已生成的 dist
```

浏览器实验不需要 API Key、账号、在线模型或实时交易接口。依赖安装时需要 npm 网络访问；安装后运行站点不会发送交易指令。

## 课程结构

| 阶段 | 课程 | 关键问题 |
|---|---|---|
| 01 数学基础 | 01–04 | MW 与 MWh、向量矩阵、概率期望、导数与梯度 |
| 02 神经网络 | 05–08 | 线性基线、神经元、多层网络、反向传播、序列与不确定性 |
| 03 电力与市场 | 09–12 | 物理平衡与参与者、中长期/现货/辅助服务/绿电、报价出清、输电约束 |
| 04 预测与验证 | 13–16 | 负荷和风光、电价尖峰、时间回测与泄露、分位数与情景 |
| 05 交易决策 | 17–20 | 采购覆盖、日前实时结算、储能与虚拟电厂、随机优化/CVaR/RL |
| 06 工业应用 | 21–24 | 中国与安徽规则入口、售电业务流程、一天的综合算例、评估与进阶 |

包含 **24 课、96 个正文小节、24 个详细数字算例和24道带逐项反馈的自检题**。每章有学习目标、先修链接、紧邻正文的图片、读图提示、误区、适用边界和原始来源。

已有神经网络背景的读者可从第09课建立电力市场直觉，再回看数学基础。面向业务应用可从第17课进入采购与结算，但仍应补齐所需先修知识。阅读时间是估计，不记录学习进度，也不作为完成要求。

## 12 个可计算实验

| 路由 | 内容 | 主要交互 |
|---|---|---|
| `#/lab/energy` | 功率、电量与费用 | 改变 MW、小时和元/MWh，观察面积与费用 |
| `#/lab/expectation` | 概率与期望 | 场景权重归一化、期望贡献、波动 |
| `#/lab/neuron` | 神经元 | 标准化、权重、偏置、ReLU 与预测 |
| `#/lab/gradient` | 梯度训练 | 真实梯度更新、拟合和损失曲线、步进/播放 |
| `#/lab/merit-order` | 报价出清 | 逐档接受、同价分配、负报价、供给缺额 |
| `#/lab/congestion` | 两区输电约束 | 线路容量、供给分配和边际成本 |
| `#/lab/forecast` | 负荷预测 | 合成气温、固定基线与特征模型对比 |
| `#/lab/backtest` | 滚动回测 | 按时揭示结果，对比正确流程与未来泄露 |
| `#/lab/quantiles` | 分位数 | 不对称损失、候选预测与经验分位数 |
| `#/lab/settlement` | 日前实时双结算 | 正负偏差、两笔账款、购电/发电视角 |
| `#/lab/hedge` | 采购覆盖 | 锁价比例、情景成本、期望与上尾CVaR |
| `#/lab/storage` | 储能 | 充放电、库存、效率、功率裁切、步进/播放 |

控件结果由 `src/labs/math.ts` 计算，数值层与显示分离。实验有预设、重置、单位和边界说明；四类逐步实验支持步进与手动播放，切页或隐藏页面时清理计时器，减少动态效果模式下采用单步。

## 图解与阅读功能

- **8组、16张实际生成的WebP插图**；中文使用中文图，英文使用英文图。正文、画廊、放大和下载共用语言映射。
- 图解库与实验库都有分类和搜索；全局搜索支持 `Ctrl/Cmd + K`，覆盖正文、实验与术语。
- 侧栏保留展开状态和滚动位置；当前课程高亮。手机有独立导航、遮罩和焦点管理。
- 支持浅色、深色、跟随系统，以及大字号。只保存语言、外观与字号偏好。
- 23条一手来源、36个双语术语。规则显示文件状态与核对日期。
- 单章下载和完整中英教材导出。生成式图片帮助理解概念；精确公式、数据图和计算结果由代码与正文表达。

生成提示词和最终资产路径见 [配图说明](docs/illustrations.md) 与 [image-prompts.json](docs/image-prompts.json)。

## 教学模型与市场来源

规则来源核对日期为 **2026-11-15**。课程区分稳定原理、明确假设的教学模型、地方实施规则和征求意见文件，详见 [来源与边界](docs/market-sources.md)。

- 2025版《电力中长期市场基本规则》自2026-03-01施行，并替代2020规则和2024绿电专章。
- 2023现货试行规则文载有效期截至2026-10-15，本课程仅将其作为历史机制参考；2026修订稿按征求意见状态标注，不当作已生效规则。
- 安徽现货于2026-09-09转正式运行；状态公告用于确认运行状态，不能替代完整结算细则。
- 统一边际出清实验采用单区、固定需求、无网络约束的简化；两区实验是运输模型，不是完整潮流或SCUC/SCED。
- 双结算实验计算电能量费用，未包含完整电费的全部项目。数量输入是MWh，MW需先乘时长。
- 储能明确充放电效率、功率与能量上限、互斥及期末库存；不把库存或模拟现金流当成现场利润。
- 预测实验采用确定性合成数据。真实日前任务只能使用发布时已知的信息，包括当时的天气预报版本。

## 工程与验证

技术栈：Vite、TypeScript、KaTeX、Marked、DOMPurify、Lucide。复用既有教程的阅读交互与视觉语言，不添加大型UI框架或外部服务。章节、实验及语言共用稳定ID，hash路由和相对资源支持子目录静态托管。

```bash
npm test            # 数值边界、双语完整性、引用、先修、图片和公式解析
npm run typecheck
npm run export:book
npm run build
npx playwright install --with-deps chromium
npm run test:e2e     # 真实桌面/手机浏览器验收，预览端口4175
```

CI位于仓库 `.github/workflows/power-trading-atlas.yml`，在相关PR和主分支改动时执行检查，保留浏览器报告、截图和构建产物。当前实际验证结果见 [验证记录](docs/verification.md)。

## 教材导出与发布

`npm run export:book` 从同一份课程数据生成 `public/downloads/power-trading-atlas-zh.md` 和 `power-trading-atlas-en.md`，包含全部正文、算例、反馈、边界及来源。Markdown中的图片位于相邻的 `images` 目录；单独下载Markdown不会自动下载图片，离线图文阅读应保留整个站点目录结构。

执行 `npm run build` 后可以将 `dist/` 部署到静态托管服务。不要直接双击源文件或将源码根目录作为生产输出。此说明描述发布方法，不表示已经开通公共网站。

设计与目录职责见 [docs/design.md](docs/design.md)。
