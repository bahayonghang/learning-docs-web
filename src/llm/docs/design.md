# LLM Atlas：课程与交互设计

## 目标与读者

让有基本计算能力、尚未系统理解大语言模型的读者，从具体数字建立理解，再走到 Transformer、训练、推理和应用。神经网络基础较好的读者可以从文字表示开始，但课程保留显式先修链接。

课程沿用仓库的独立站点约定：源码、工具链、图片、测试、说明放在 `src/llm/`，Vite + TypeScript，MarkDown/KaTeX 渲染，Lucide 图标，中英完整对应。主题使用暖纸色、陶土橙、石墨色和少量灰绿色，提供浅色、深色与跟随系统外观。

## 六个阶段

| 阶段 | 课程 | 读者应能完成的任务 |
|---|---|---|
| 数学工具 | 01 向量与矩阵；02 概率、softmax 与交叉熵；03 导数与梯度 | 算一次加权预测、概率与参数更新 |
| 神经网络 | 04 神经元；05 多层网络与反向传播；06 泛化 | 解释非线性、误差传播和训练/验证的区别 |
| 文字表示 | 07 分词；08 嵌入；09 语言建模目标 | 把文本变成 token ID、向量与错位标签 |
| Transformer | 10 QKV 与因果注意力；11 多头与 block；12 位置与 decoder | 沿数据流解释每个模块、形状与变长输入 |
| 训练与推理 | 13 预训练/SFT/偏好；14 自回归与采样；15 KV cache | 区分训练并行性、生成循环、缓存与权重 |
| 应用实践 | 16 LoRA；17 RAG；18 评估与综合案例 | 设计一个有出处、能评估、有边界的文档助手 |

章节顺序和 ID 定义在 `src/content/`。阅读时长是教学估计，不是测量结果，也不存学习完成状态。

## 每一课的结构

1. 用问题说明本课为什么值得学，并给出明确目标与先修知识。
2. 用三个以上小节递进解释，公式紧跟符号、维度或数字说明。
3. 在第一段机制讲解后立即插入概念图，配三条读图说明。
4. 给出可以手算的完整数字例子。
5. 嵌入相关的实时实验，支持单独打开。
6. 解释常见误区与本课的简化边界。
7. 用选择题检查理解，每个选项都有独立解释。
8. 链接到可核验的原始论文、教材和官方文档。

正文、自检反馈、图注、来源说明、术语、实验及界面均使用同一套章节/实验 ID 配对中英文。语言切换同时更换图内文字对应的图片文件。文献题名保持原始身份。

## 十个实验的计算对象

| 实验 ID | 计算对象 | 主要边界 |
|---|---|---|
| `vectors` | 点积与矩阵乘法 | 二维/小矩阵教学示例 |
| `neuron` | 加权和、偏置与激活 | 单个神经元，不是完整训练 |
| `gradient` | 二次函数梯度更新 | 不是深层模型实际损失曲面 |
| `softmax` | 温度分布、熵与交叉熵 | 少量固定候选 token |
| `tokenizer` | 固定教学 BPE 规则合并、文字还原 | 不是某个真实模型的 tokenizer |
| `attention` | QK 打分、因果掩码、softmax、V 加权 | 单头小矩阵，不是真实语言模型解释 |
| `generation` | 固定种子的二元模型采样、top-p 与 EOS | 手工概率模型，无真实 LLM 调用 |
| `kv-cache` | 原始 K/V 张量字节数，MHA/GQA/MQA 对照 | 不含权重、激活、分配开销 |
| `lora` | 单个线性层的稠密与适配器参数量 | 参数占比不等于完整显存占比 |
| `retrieval` | 双语虚构文档的词面覆盖率与证据拼装 | 不是向量检索，不生成真实回答 |

数值内核与 DOM 展示分开。动画使用计算状态推进，单步、自动播放、重置共享相同状态；离开页面或关闭内嵌实验时释放计时器与监听器。随机实验使用可见、可改的种子。

## 图像与精确表达

七个主题各有中文、英文两幅原创生成图，配图的完整提示词和来源见 [illustrations.md](illustrations.md)。图片承担直觉引导，不承担精确概率、公式或网络拓扑的证明。精确数据、张量形状、注意力热图、曲线与连线由网页计算和绘制。

图解知识库支持分类、关键词搜索、放大和下载。文章中的图紧邻相关解释，并链接到当前语言的资源。图片使用 WebP、本地相对路径、尺寸声明和懒加载（首页主图优先加载）。

## 架构与内容边界

- `src/content/` 是规范内容；页面、搜索、自检和教材导出读取同一份数据。
- `src/labs/math.ts` 不依赖浏览器，是数值验证入口；实验界面负责说明和状态。
- `src/markdown.ts` 先保护代码和公式，再解析 Markdown、清洗 HTML，最后由 KaTeX 渲染。禁止信任公式中的 HTML。
- 页面使用 hash 路由与相对资源，可部署在子路径。根仓库不新增共享开发服务器。
- 浏览器仅保存语言、主题和字号；不保存阅读完成状态、笔记、收藏、个人画像或历史。
- 词面检索所用设备记录均为教学虚构内容，不是用户的真实生产资料。
- 不调用模型服务，不使用 API Key，不宣称训练了真实大模型或取得工业效果。

## 验证

`npm test` 检查数值行为、先修图、双语完整性、引用、图像文件、公式和导出。`npm run build` 执行严格 TypeScript 检查和静态构建。`npm run test:e2e` 在生产预览上检查桌面与移动浏览器的路由、计算交互、图片、本地化和布局，截图供人工复核。实际执行结果与环境限制单独记录在 [verification.md](verification.md)。
