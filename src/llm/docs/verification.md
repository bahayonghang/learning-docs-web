# LLM Atlas 验证记录

## 验证范围

验证课程内容、公式渲染、数值计算、语言/图像配对、导出、静态构建，以及桌面和手机的页面交互。原始插图与数值图使用不同的验证方式：插图逐张检查可见主题与文字，数值图检查真实计算逻辑。

## 已执行的本地检查

- 在 Node.js 24.22.1、npm 11.9.0 环境按本目录依赖安装并执行检查。
- `npm run check` 通过：19/19 项数值与内容测试、教材导出、严格 TypeScript 检查和生产构建。
- 数值内核覆盖点积、形状错误、softmax 稳定性、零温度、交叉熵、梯度收敛/过冲、激活、注意力、因果屏蔽、top-p、固定种子、BPE 还原、KV、LoRA 和词面检索。
- 内容检查覆盖 18 个章节 ID、六阶段先修关系、双语正文/反馈/来源、实际图片文件、KaTeX 公式和教材导出。

- 已重新导出中文和英文的完整教材。

独立审阅修复了根页面深色主题继承、手机搜索按钮可访问名称，以及配图读图说明与实际图像之间的对应关系。课程数值例子、矩阵约定和中英文表述另行核对。

## 边界

- 测试保证已检查的计算性质与界面行为，不证明读者一定掌握全部内容。
- 教学分词、二元生成和词面检索不等于真实 tokenizer、LLM 或向量数据库。
- KV 测试是张量字节数核验，不是完整设备显存或吞吐量评估。
- 本次未部署线上网站，没有测量真实模型能力或工业效果。
