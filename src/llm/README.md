# LLM Atlas · 从基础理解大语言模型

[English README](README.en.md) · [课程设计](docs/design.md) · [配图来源与完整提示词](docs/illustrations.md) · [验证记录](docs/verification.md)

从向量、概率、导数和神经元出发，通过小数字例子、原创概念插图和实时计算实验，逐步理解文本表示、Transformer、训练、自回归生成与实际应用。中文和英文都有完整正文、图注、练习反馈、术语和交互说明。

**6 个阶段 · 18 节双语课程 · 10 个计算实验 · 7 对原创中英配图（14 张）· 30 个术语 · 20 项原始资料**

![LLM Atlas 中文首页，真实浏览器截图](docs/screenshots/home-desktop-zh.webp)

## 快速运行

需要 **Node.js 22.12 或更新版本**以及 npm。从仓库根目录开始：

```bash
cd src/llm
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:5173/`；端口被占用时以实际输出为准。若已安装 [just](https://just.systems/)，也可以在本目录直接运行 `just dev`，它会按锁文件自动准备依赖。Windows 的 just 入口使用 `cmd.exe`，无需额外配置 Bash。

站点和实验不需要 API Key、模型账户、GPU、数据库或后端。首次安装依赖需要联网；生产静态资源、字体、图片、公式和实验计算均在站点自身提供。原始资料链接指向外部网站。

## 从哪里开始

| 已有基础 | 建议入口 | 需要掌握的内容 |
|---|---|---|
| 数学或神经网络尚不熟悉 | 第 01 课 | 从向量、概率、梯度和一个神经元开始 |
| 已学过神经网络 | 第 07 课 | 确认矩阵乘法、交叉熵和反向传播后，进入文本表示 |
| 已理解 Transformer 和生成 | 第 16 课 | 比较 LoRA、RAG，并设计评估与证据约束 |

每课按“问题与目标 → 逐步解释 → 贴近正文的图解 → 数字代入 → 动手实验 → 误区与边界 → 自检 → 原始资料”组织。先预测一个结果，再修改一个参数，最后用自己的话解释为什么改变。

| 阶段 | 课程 | 核心问题 |
|---|---|---|
| 01 数学工具 | 01–03 | 数字怎样表示信息？分数怎样成为概率？参数怎样更新？ |
| 02 神经网络 | 04–06 | 非线性为什么必要？误差如何回传？训练好为何仍会犯错？ |
| 03 文字表示 | 07–09 | token 是什么？嵌入是什么？训练标签怎样构造？ |
| 04 Transformer | 10–12 | QKV 怎么算？一个 block 做什么？怎样处理顺序与变长？ |
| 05 训练与推理 | 13–15 | 预训练与对齐有什么不同？怎样逐步生成？缓存存了什么？ |
| 06 应用实践 | 16–18 | 何时用 LoRA 或 RAG？怎样评估工业文档助手？ |

时间标注是阅读估计，动手推导和实验通常需要额外时间。站点不保存学习进度、阅读历史、笔记或收藏。

## 页面与实验

| 路由 | 用途 |
|---|---|

| `#/course` | 可搜索、展开的完整目录 |

全站搜索可用 `Ctrl+K` 或 `⌘K` 打开；覆盖中英文标题、正文知识点、实验和术语。侧栏保留展开状态与滚动位置，当前章节始终高亮。手机端提供抽屉式导航、键盘焦点管理和跳转主内容入口。

| 实验 | 实际计算/交互 |
|---|---|
| 向量与矩阵 | 二维向量、点积、矩阵乘法与几何可视化 |
| 一个神经元 | 权重、偏置、ReLU/sigmoid/线性激活与实时输出 |
| 梯度下降 | 真实二次损失更新，单步/播放/重置，观察收敛和过冲 |
| Softmax | logits、温度、概率、熵与交叉熵 |
| 教学 BPE | 固定合并规则、逐步切分、空格保留与原文还原 |
| 因果注意力 | QK 打分、softmax、因果 mask、热图与 V 加权结果 |
| 逐 token 生成 | 固定种子、二元概率模型、温度、top-p、EOS 与播放 |
| KV cache | 层数、batch、长度、KV 头数和精度的内存计算 |
| LoRA | 单层稠密参数与低秩适配器参数的精确比较 |
| 文档检索 | 本地虚构资料的词面匹配、top-k、出处和证据拼装 |

只有语言、外观和字号保存在当前浏览器的 `llm-atlas-preferences-v1` 中。浅色、深色和跟随系统可循环切换；动画尊重系统减少动态效果的偏好。

## 配图与内容准确性

七个主题各有中文、英文独立图片。图片由内置图像生成功能原创生成，统一使用纸张、陶土橙、石墨和灰绿的插画风格；存为 `public/images/<figure-id>-<locale>.webp`，每张 1536 × 1024。

配图负责建立直觉。精确公式、矩阵形状、概率、注意力热图和计算曲线由正文或代码表达；生成插图不是精确网络图或实验测量结果。完整提示词与边界见 [illustrations.md](docs/illustrations.md)。

课程特别区分：

- 序列长度与特征维度；可变长与无限上下文。
- 训练时多个位置的并行损失，与推理时逐 token 生成。
- token ID、输入嵌入和经过上下文加工的隐藏表示。
- 因果掩码在 softmax 前屏蔽未来信息。
- 原始 encoder–decoder Transformer 与本课程主线的 decoder-only 架构。
- KV cache、模型权重、外部知识库和长期记忆。
- SFT、PPO/RLHF、DPO 的不同目标与选择关系。
- LoRA 参数占比与完整显存占比。
- 检索相关性、证据适用性和回答正确性。

资料优先使用 D2L、原始 Transformer/RoPE/LoRA/RAG/DPO 等论文、PyTorch 与 Hugging Face 官方文档。每一课链接到具体出处，不依赖模型价格或排行榜等容易变化的信息。

## 检查、构建与导出

```bash
npm test                 # 数值内核、双语、来源、图片和公式
npm run export:book      # 重新导出两种语言的完整教材
npm run typecheck        # 严格 TypeScript 检查
npm run build            # 类型检查 + 生产构建
npm run preview          # 查看 dist 生产版本
```

`npm run check` 依次导出教材、执行测试并构建。教材位于 `public/downloads/llm-atlas-zh.md` 与 `llm-atlas-en.md`，含正文、数字例子、图注、自检答案、术语和原始资料。Markdown 图片路径指向相邻 `images` 目录；单独下载文字不会自动下载图片，保留完整静态目录即可正常显示。

浏览器测试使用 Playwright，首次需安装测试浏览器：

```bash
npx playwright install chromium
npm run build
npm run test:e2e
```

套件在桌面和手机尺寸上验证双语路由、图片、公式、交互与溢出。GitHub Actions 工作流位于仓库根目录 `.github/workflows/llm-atlas.yml`，保留截图与失败追踪。[首次真实浏览器验收](https://github.com/bahayonghang/learning-docs-web/actions/runs/43799536971)结果为 21 项通过、1 项桌面不适用的手机测试跳过；手机项目中的该项测试通过。截图、数值与内容测试结果见 [verification.md](docs/verification.md)。

## 静态发布

输出目录为本目录的 `dist/`。使用相对资源 `base: './'` 和 hash 路由，可以放在域名根目录或 `/llm/` 等子路径。静态托管的项目根目录应为 `src/llm`，安装命令 `npm ci`，构建命令 `npm run export:book && npm run build`，输出目录 `dist`。

通过 HTTP(S) 访问构建结果；直接双击 `index.html` 不等同于启动站点。本次创建提供源代码和验证工作流，不自动开通 GitHub Pages 或其他线上部署。

## 教学模型边界

这里没有训练真实 LLM。分词实验应用教学规则，生成实验使用小型手工二元模型，检索实验用词面覆盖率而非语义嵌入。每个实验在页面内说明省略了什么。设备文档案例均为虚构，不包含真实生产数据，也不会输出可直接下发到 DCS/PID 的控制指令。
